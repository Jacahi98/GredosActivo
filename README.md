# Gredos Activo

Web de Gredos Activo, un negocio local en Navarredonda de Gredos (Sierra de
Gredos) que combina turismo activo con los servicios del día a día del
pueblo: es también la Estación de Servicio Gredos. "Aventura en la sierra,
servicio en el pueblo."

## Qué tiene la web

- Turismo activo: bicicleta de montaña, parque de cuerda, paintball y tiro
  con arco, para grupos y particulares con monitores y material.
- Gasolinera y reparto: autoservicio 24 horas y reparto de gasóleo a
  domicilio para calefacción.
- Badge de reseñas de Google enlazado a Maps y llamada directa por teléfono.
- Galería y página de contacto.
- Transición de página en forma de cortina de montaña entre secciones.

## Stack

Next.js · TypeScript · Tailwind CSS · Framer Motion

## Desarrollo local

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).
